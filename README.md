# MedClub demo

A Flutter pharmacy buyer demo. Catalog, cart, orders, inbox, and profile data live
in memory and reset when the app closes. The seeded user is **Jb Jason**.

## Visual assets

The manufacturer logos are local, size-optimized copies from the companies'
official websites:

| Company | Source |
| --- | --- |
| Square Pharmaceuticals | https://www.squarepharma.com.bd/images/squarelogo.png |
| Beximco Pharma | https://beximco-pharma.com/cdn/bpl/images/bpl-logo.png |
| Incepta Pharmaceuticals | https://www.inceptapharma.com/images/logonu.png |
| Renata PLC | https://renata-ltd.com/logo-blue.png |
| ACI Pharmaceuticals | https://www.aci-bd.com/assets/images/aci-plc.png |

The product names, listings, prices, and manufacturer associations in this app
are fictional demo data. The logos do not imply company endorsement.

The app uses the [Manrope variable font](https://github.com/google/fonts/tree/main/ofl/manrope)
under its [SIL Open Font License](assets/fonts/manrope/OFL.txt). The five logo
files total about 12 KB. Only those logos and the single 165 KB font are
declared as app assets; older unused images and font weights remain in the
repository but are excluded from the app bundle.
